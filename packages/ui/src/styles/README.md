`shadcn.css` is the unmodified `dist/tailwind.css` from shadcn 4.21.0, retained under the accompanying MIT license. It supplies the state variants and animations used by the existing shared components. Keeping this asset beside the copied UI components avoids installing the scaffold CLI and its unrelated MCP/globbing dependency tree for builds. When updating the design system, compare this file with the upstream package stylesheet and retain its license.
