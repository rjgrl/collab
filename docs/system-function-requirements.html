Alumni Tracking System

System function requirements by user

A higher user also has every function of the users below them. Admin includes Staff / Coordinator and User / Alumni. Staff / Coordinator includes User / Alumni.

Users

UserSystem roleWhat this user is for
Adminsuper_adminRuns the whole system, including accounts, roles, and the audit log.
Staff / CoordinatorstaffMaintains departments, programs, faculties, alumni, tracking, files, reports, and integrations.
User / AlumniviewerSigns in and reads academic structure, alumni profiles, evidence, the dashboard, and reports. A new sign-up receives this role.

Admin

Functions only the Admin can perform. The Admin also has every function in the Staff / Coordinator and User / Alumni sections.

CodeNameDescription
RBAC-001View usersLists accounts and the roles assigned to each account.
RBAC-002Create userCreates an account with a name, email, password, and one or more roles.
RBAC-003Update userChanges a user's name, password, status, or role assignments.
RBAC-004Disable userSets an account to disabled so it can no longer sign in.
RBAC-005View rolesLists roles and the permissions attached to each role.
RBAC-006Create roleCreates a role with a key, name, description, and a set of permissions.
RBAC-007Update roleChanges a role's name, description, or permission set.
RBAC-008Delete roleDeletes a role that is not a protected system role.
RBAC-009View permissionsLists the permission catalog grouped by module.
RBAC-010Enforce accessEvery protected action checks the caller's permissions. A missing permission is rejected. Permissions come from the user's roles.
AUD-001View audit logLists recent activity, including the actor, action, entity, summary, and time.

Staff / Coordinator

Functions the Staff / Coordinator can perform beyond read-only access. This user also has every function in the User / Alumni section. This user cannot manage accounts, roles, permissions, or the audit log.

CodeNameDescription
ACAD-002Create departmentCreates a department with a code, name, and description.
ACAD-003Update departmentChanges a department's code, name, or description.
ACAD-004Delete departmentSoft-deletes a department so it no longer appears in active lists.
ACAD-006Create programCreates a program and attaches it to a department.
ACAD-007Update programChanges a program's details or moves it to another department.
ACAD-008Delete programSoft-deletes a program.
ACAD-010Create facultyCreates a faculty record.
ACAD-011Assign faculty to departmentAdds a faculty to one or more departments, or updates that assignment.
ACAD-012Delete facultySoft-deletes a faculty record.
ALUM-003Create alumniCreates a profile with student details, contact info, and a required program. The student number must be unique.
ALUM-004Update alumniEdits student details, contact info, employment status, or the attached program.
ALUM-005Delete alumniSoft-deletes an alumni record.
ALUM-008Add employmentRecords an employer, job title, industry, location, dates, and whether the job is current. The profile's employment status is updated from that record.
ALUM-009Remove employmentRemoves an employment record from a profile.
ALUM-010Update trackingMarks a graduate tracked or untracked and records a tracking event with a note and timestamp.
ALUM-011Attach alumni to programSets the program on an alumni record. That program belongs to one department.
RPT-002Export CSVDownloads an alumni CSV, optionally filtered by department and tracked status.
RPT-003Export Google SheetsExports alumni rows to Google Sheets when that integration is configured.
FILE-001Upload evidenceUploads an evidence file or image and attaches it to an alumni profile.
FILE-003Delete evidenceSoft-deletes an evidence file.
FILE-004Store imagesStores images on imgBB, Google Drive, or local disk, depending on which provider is configured.
INT-001reCAPTCHAEnables or disables reCAPTCHA. Live keys call Google; missing keys use the local checkbox.
INT-002Google authenticationEnables or disables Google sign-in. It is available only when client id and secret are set.
INT-003Google Drive evidenceSends evidence uploads to Google Drive when a service account and folder are configured; otherwise they stay on local disk.
INT-004EmailSends email through SMTP when configured. Otherwise the message is logged. Can send a test message and a message to an alumnus.
INT-005Image hostingSends image uploads to imgBB or Google Drive when configured, and to local storage otherwise.
INT-006Google Forms importAccepts a signed Google Forms webhook and creates or updates alumni rows.
INT-007Google Sheets importImports alumni rows from the configured spreadsheet.
INT-008CSV importImports pasted or uploaded CSV rows as alumni and records success count, error count, and row errors.
INT-009Integration statusShows which modular integrations are enabled and whether their credentials are present.
INT-010Toggle integrationEnables or disables a modular integration without changing the rest of the system.

User / Alumni

Functions a User / Alumni can perform. This is the role given to a new sign-up. Access is read-only.

CodeNameDescription
AUTH-001Sign inSigns in with email and password. A valid account receives a session; a wrong password or disabled account is rejected.
AUTH-002Sign upRegisters with name, email, and password and receives a session. Duplicate emails are rejected. The first account becomes Admin; later accounts become User / Alumni.
AUTH-003Sign outEnds the current session and clears the session cookie.
AUTH-004Current sessionReturns the signed-in user, assigned roles, and effective permissions, or an empty session when nobody is signed in.
AUTH-005Google sign-inSigns in through Google and returns to the app with a session, when Google OAuth is configured and enabled.
AUTH-006Bot checkSign-in and sign-up require reCAPTCHA when it is enabled. Live keys use Google reCAPTCHA; otherwise a local "I am not a robot" checkbox is used.
ACAD-001View departmentsLists and opens departments, including their programs and assigned faculties.
ACAD-005View programsLists programs and the department each program belongs to.
ACAD-009View facultiesLists faculties and the departments they belong to.
ALUM-001Search alumniLists alumni and filters by name or student number, department, program, graduation year, and tracked or untracked status.
ALUM-002View alumni profileOpens one profile, including program and department, contact, employment history, tracking events, and evidence files.
ALUM-006Student detailsReads student number, name, middle name, required gender (Male or Female), and graduation year on a profile.
ALUM-007Contact infoReads mobile number, personal email, and Facebook account on a profile.
FILE-002View evidenceOpens or downloads an evidence file.
DASH-001Graduate statisticsSees total graduates, tracked count, untracked count, and tracked percentage. Percentage is tracked divided by graduates, rounded to two decimals.
DASH-002Statistics by departmentSees graduate count, tracked count, and tracked percentage for each department.
RPT-001View reportsOpens graduate and alumni report totals. Export stays with Staff / Coordinator and Admin.
