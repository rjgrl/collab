## Confirmed correction

Evidence downloads checked only the evidence file's deleted state. A still-active file attached to an archived alumnus returned 200 despite the profile no longer being visible. The new synthetic HTTP test first failed (200 vs 404), then passed after adding an active-parent predicate. Active-record downloads retain their current permission contract. This closes one archive-state inconsistency; it is not an ownership/department isolation change or proof of a complete deletion cascade. Full academic-parent/archive/batch-import behavior and externally cached/public images still need review.

Completion logs now add a safe outcome category and still exclude URL/query/body/header secret markers. Safe user projections, export limits/formula neutralization and synthetic role denials remain tested. Soft deletion does not anonymize or erase data. Actual export/download audit coverage and retention are not declared complete.

The Philippine [Data Privacy Act and its IRR](https://privacy.gov.ph/the-data-privacy-act-and-its-irr/) frame collection, use, disclosure and deletion. The [NPC IRR](https://privacy.gov.ph/implementing-rules%20regulations-data-privacy-act-2012/) supports purpose/proportionality, retention and appropriate security review. The institution's privacy/legal owner must determine lawful basis, notices, rights handling, security/incident processes and any applicable government-agency requirements. Technical test passes do not establish compliance.

Owner acceptance needed: approve global contact/employment/evidence/export scope; identify controller/processors/DPO and provider terms; complete privacy-impact/data-flow review; set per-data retention/erasure and backup exceptions; define rights/correction/deprovisioning workflows; implement approved minimization/auditing/cleanup and verify synthetic erasure/replay consistency. Policy-dependent changes and real deletion remain blocked rather than assumed.
