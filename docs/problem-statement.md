# Problem Statement

> **Requirement Status:** A formal problem statement is not specified in the provided system guide.

The source guide is a module sketch for an **Alumni Tracking System**. From that sketch, the system is intended to:

- Control access using Roles, Users, and Permissions as **RBAC (Rule Based Access Control)**.
- Maintain Departments, Programs, Faculties, and Alumni Profiles.
- Attach faculties to departments and attach alumni to programs that attach to departments.
- Show dashboard counts for graduates, tracked graduates, and percent tracked.
- Use modular integrations: reCAPTCHA, G. Auth, G. Drive (uploading of evidence), Email, Image BB / G. Drive, G. Forms, and G. Sheets.

> **Assumption:** The business problem is tracking alumni/graduates and related academic structure. The guide does not state the problem, users, or success criteria in narrative form.
